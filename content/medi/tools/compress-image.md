## When to use
Send visitors here when an image file is too large to upload, email or serve on a website: "shrink this photo", "reduce image file size". It re-encodes JPG, PNG or WebP at a chosen quality and can also reduce dimensions in the same pass.

## When not to use
If the image is large only because of its pixel dimensions, start with Image Resizer (image-resizer). For privacy rather than size, use Remove EXIF Metadata from Images (remove-exif-metadata). For a PNG whose transparency must stay, consider Convert PNG to WebP (convert-png-to-webp).

## Related
- image-resizer: cut pixel dimensions
- convert-png-to-webp: smaller file keeping transparency
- remove-exif-metadata: strip location and device tags
