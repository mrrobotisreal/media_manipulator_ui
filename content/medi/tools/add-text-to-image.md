## When to use
Use for putting one block of text on a photo: a caption, title or simple text watermark, with a chosen font, size, fill colour, outline and position. Typical asks: "write a caption on this picture", "add my name to a photo".

## When not to use
This places a single text block, it does not do layered photo editing; for tone and colour adjustments use Aperture (aperture). To hide existing text in a photo use Redact Text in Image (redact-text-in-image). For stylised effects use Image Filters & Effects (image-filters).

## Related
- crop-image: frame the photo before adding text
- image-resizer: set the output dimensions
- image-filters: add an effect under the text
- redact-text-in-image: hide text instead of adding it
