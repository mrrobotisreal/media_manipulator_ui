## When to use
Send visitors here when they want to hide people's faces in a photo before publishing it, with a blur, pixel mosaic or black box, for all detected faces or only chosen ones: "blur faces", "anonymize people in this picture".

## When not to use
Name tags, licence plates and screens are not faces: use Redact Text in Image (redact-text-in-image) or Remove Object from Photo (remove-object-from-photo). To remove a person entirely, use the object remover. Detection can miss faces, so it is not a sole safeguard.
