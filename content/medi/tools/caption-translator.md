## When to use
Send visitors here when they already have an .srt or .vtt subtitle file and want it in another language with timings and cue order unchanged. Fits "translate my subtitles to Spanish".

## When not to use
If there is no caption file yet, create one first with SRT Generator (srt-generator) or VTT Caption Generator (generate-vtt-captions). It only translates caption files, not documents or audio.

- generate-vtt-captions: make VTT captions
