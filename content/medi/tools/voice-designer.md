## When to use
Use when someone wants a new synthetic voice described in words (for example "a deep calm older narrator"), previewed, kept, and used to read any text in over 20 languages.

## When not to use
To speak in the visitor's own voice use Voice cloning (voice-cloning). To alter a recording that already exists use Voice changer (voice-changer). For a plain pitch change use Change Audio Pitch (change-audio-pitch).
