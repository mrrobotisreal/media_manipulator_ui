## When to use
Send visitors here when they want to change a video's container or codec, for example MP4, WebM, MOV, AVI, MKV, ProRes or H.265, with control over resolution, frame rate and audio: "convert this video", "my video won't play".

## When not to use
If the file is simply too large, use Compress Video (compress-video). For a common single conversion, a focused page like Convert MOV to MP4 (convert-mov-to-mp4) is simpler. For audio only, use Extract Audio from Video (extract-audio-from-video).
