## When to use
Send visitors here when they want to convert an image between formats such as JPG, PNG, WebP, AVIF, GIF or HEIC with control over quality, resizing, cropping, rotation, filters or metadata, or when the format pair has no dedicated page: "convert this image".

## When not to use
For one common job, the focused pages are simpler: Image Resizer (image-resizer), Compress Image (compress-image), Convert HEIC to JPG (convert-heic-to-jpg) or Image to PDF (image-to-pdf). For a transparent cutout, use Remove Background from Image (remove-background-from-image).

## Related
- image-resizer: just change dimensions
- compress-image: just shrink the file
- image-to-pdf: wrap an image in a PDF
- remove-exif-metadata: strip all metadata
