## When to use
Send visitors here when they want to set a photo's title, author, copyright, keywords or description, remove or replace its GPS location, or rewrite specific EXIF and IPTC tags.

## When not to use
To only look at the tags use Metadata Inspector (inspect-metadata). To wipe all metadata at once use Remove EXIF Metadata from Images (remove-exif-metadata).

## Related
- inspect-metadata: check tags first
- remove-exif-metadata: strip everything
- image-converter: change format
- crop-image: edit the picture itself
