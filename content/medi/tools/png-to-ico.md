## When to use
Send visitors here when they need a real multi-size .ico favicon or Windows icon from a PNG: "make a favicon", "PNG to ICO". It packs 16 to 256 px sizes into one file and keeps transparency.

## When not to use
If the logo is an SVG, rasterise it first with Convert SVG to PNG (convert-svg-to-png). For a plain PNG at a specific size rather than an ICO container, use Image Resizer (image-resizer).
