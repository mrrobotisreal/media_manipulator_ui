## When to use
Use when someone wants a flat, poster-style graphic look by reducing each colour channel to a few levels with hard tonal steps. Typical asks: "posterize this photo", "pop-art style flat colours".

## When not to use
It is an effect, not a correction: to remove banding use Reduce image noise (reduce-image-noise) or Curves (photo-curves). For a smaller file use Compress Image (compress-image) instead of cutting colours.
