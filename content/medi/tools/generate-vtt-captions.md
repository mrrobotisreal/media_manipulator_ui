## When to use
Use when someone needs a .vtt caption file for an HTML5 video player or YouTube, transcribed by AI from the speech with timed cues and automatic language detection. Typical asks: "make WebVTT subtitles for my video".

## When not to use
If they need .srt instead use SRT Generator (srt-generator). For a plain text transcript use Transcribe Video (transcribe-video). To translate existing captions use Caption Translator (caption-translator).

## Related
- srt-generator: SRT format captions
- transcribe-video: plain text transcript of a video
- caption-translator: translate the captions
- content-studio: edit video with captions in Darkroom
