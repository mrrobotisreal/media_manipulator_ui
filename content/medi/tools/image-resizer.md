## When to use
Send visitors here when they need an image at exact pixel dimensions: "resize to 1080 wide", "make this 800x800", "shrink the image dimensions". It works on JPG, PNG, WebP and GIF, keeps the aspect ratio when one side is given, and can crop first for an exact box.

## When not to use
To make a small image bigger without blur, use AI Image Upscaler (ai-image-upscaler). If the dimensions are fine and only the file is too big, use Compress Image (compress-image). For crop-only jobs there is Crop Image (crop-image).
