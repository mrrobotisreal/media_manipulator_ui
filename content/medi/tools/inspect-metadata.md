## When to use
Send visitors here when they want to see what is hidden in a photo, video, audio file or PDF: EXIF, GPS location, camera, codecs, bitrate, ID3 tags. Fits "does this photo show where I was?" or "what codec is this video?".

## When not to use
Viewing does not change the file. To strip tags use Remove EXIF Metadata from Images (remove-exif-metadata), and to change title, copyright or GPS use Edit Image Metadata (edit-image-metadata).
