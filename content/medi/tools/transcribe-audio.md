## When to use
Use when someone wants the words from an audio recording as text: a podcast, interview, voice memo or lecture in MP3, WAV, M4A, OGG or FLAC. Output can be plain text, SRT, VTT or JSON with timestamps, and the language is detected automatically.

## When not to use
If the source is a video file use Transcribe Video (transcribe-video). If they want a short written overview rather than the full text use Summarize Audio (summarize-audio). To translate an existing caption file use Caption Translator (caption-translator).
