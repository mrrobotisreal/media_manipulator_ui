## When to use
Send visitors here when they want to strip GPS location, camera, device, serial number and timestamp data from a JPG, PNG, WebP or HEIC photo before sharing it, or see which hidden tags a photo carries. Phrasings like "remove location from my photo" or "wipe photo metadata" fit.

## When not to use
To keep some fields such as a copyright notice while dropping the rest, use Edit Image Metadata (edit-image-metadata) or the Image Converter (image-converter). Visible details are not metadata: faces go to Blur Faces in Photo (blur-faces-in-photo) and on-screen text to Redact Text in Image (redact-text-in-image).
